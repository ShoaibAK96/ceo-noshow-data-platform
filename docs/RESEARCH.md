# Official technical research — checked 20 October 2026
Research validates platform capability and documentation routes, not this project's deployment.

- Microsoft File System connector: https://learn.microsoft.com/en-us/connectors/filesystem/ — gateway access, path-based reads and trigger caveats. Trigger retrieval can be delayed; do not promise instantaneous delivery or an entire batch in one trigger run.
- Fabric Notebook activity: https://learn.microsoft.com/en-us/fabric/data-factory/notebook-activity — orchestration capability; not evidence of a configured pipeline.
- Office Scripts with Power Automate: https://learn.microsoft.com/en-us/office/dev/scripts/develop/power-automate-integration — script/workbook service integration.
- GitHub local repositories: https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-a-repository-from-your-local-computer-to-github-desktop
- GitHub rulesets: https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/creating-rulesets-for-a-repository

Engineering interpretation: the strongest portfolio angle is cross-platform ingestion with explicit replay, data-quality and recovery contracts. No external research is used to manufacture savings or project outcomes.
