# Provenance
src/transfer.py, office-scripts/prepare_workbook.ts, fabric/loader_v3.py, fabric/precheck_v3.py and config/fabric.example.json are sanitized derivatives of available original source files. Names and deployment identifiers were generalized; they are not byte-identical originals.

src/reference_demo.py, tests, synthetic sample, architecture docs, CI and diagram renderer are newly reconstructed portfolio assets. The demo models parsing and replay behavior locally; it does not replace Power Automate, Excel Online, Fabric or Delta. Private originals are deliberately outside this repository. No historical commit sequence was supplied; local Git begins with the packaging snapshot.
